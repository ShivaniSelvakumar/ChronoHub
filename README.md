# ⏱️ ChronoHub — Built for Every Tick

ChronoHub is my **first personal web development project**, created to practice and apply the fundamentals of **HTML, CSS, and JavaScript**.

It is a simple time-management website that brings together a digital clock, stopwatch, countdown timer, and world clock in one place.

This project was mainly built as a learning experience, and it helped me understand how the concepts I learned can come together to create a functional web application.

---

## 🌟 Features

* 🕐 **Digital Clock** — Displays the current time and updates automatically.
* ⏱️ **Stopwatch** — Start, pause, and reset the stopwatch.
* ⏳ **Countdown Timer** — Set a duration and control the countdown.
* 🌍 **World Clock** — Check the current time in different time zones.
* 🎨 **Theme** — A simple interface designed to make the application comfortable to use.

---

## 🛠️ Technologies Used

* **HTML** — For creating the structure of the application.
* **CSS** — For styling and designing the interface.
* **JavaScript** — For implementing the clock, stopwatch, timer, and world clock functionality.
